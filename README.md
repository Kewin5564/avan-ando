#### 🎯 Desafio
Desenvolver um sistema simples de relatório de vendas utilizando recursos de arrays em JavaScript.

📋 Requisitos da Atividade
Remover duplicados: utilizar Set para eliminar valores repetidos.

Filtrar vendas: aplicar filter() para selecionar apenas vendas acima de 150.

Calcular total: usar reduce() para obter a soma de todas as vendas.

Criar cópia: empregar o Spread Operator (...) para gerar uma cópia do array original.
